1. EXECUTIVE SUMMARY & PLATFORM OBJECTIVE
--------------------------------------------------------------------------------
VantagePulse AI™ is an enterprise-grade autonomous market intelligence and
competitive benchmarking software application. It delivers deep, multi-dimensional
analytics, customer sentiment telemetry, real-time ROI modeling, and complete
product taxonomy across 1,299 authentic global technology enterprises and 2,577
enterprise software products.

The platform is designed to replace tedious manual competitor research with
instant automated comparison matrixes, aspect-level natural language processing
(NLP), multilingual feedback translation, and AI-assisted conversational synthesis.

2. TECHNICAL ARCHITECTURE & STACK
--------------------------------------------------------------------------------
A. Backend & API Services:
   - Environment: Pure Node.js (Node 18 / 20 / 22 LTS compatible)
   - Zero External Dependencies: Fast, zero-overhead execution without node_modules
     dependencies, ensuring 100% cloud portability.
   - RESTful API Endpoints:
     * GET  /api/health            -> System telemetry and engine health status
     * GET  /api/companies         -> Search, category filter & pagination (1,299 companies)
     * GET  /api/companies/:id     -> Deep profile and product telemetry
     * GET  /api/products          -> Full catalog search (2,577 products)
     * POST /api/azure/sentiment   -> Dual-mode Aspect NLP engine
     * POST /api/azure/translate   -> Neural multilingual translation proxy
     * GET  /api/azure/blobs       -> Object lakehouse storage telemetry
     * POST /api/auth/login        -> RBAC session validation & security tracking
     * GET  /api/auth/logs         -> Admin-restricted security audit log
     * POST /api/ai/chat           -> Context-aware strategic AI copilot

B. Frontend & User Interface:
   - Core: Semantic HTML5, Modular JavaScript (ES6+ Classes), Vanilla High-Speed DOM
   - Responsive Design: Dynamic fluid grid, custom mobile drawer, cross-device support
   - Multi-Theme Engine: Midnight (Dark), Light (Clean), Onyx (Cyber), Azure (Enterprise)
   - Motion & Visuals: HTML5 Canvas synaptic particle animations, animated number
     counters, dynamic typewriter headers, glassmorphism layers.
   - Vector Graphics: Official lossless corporate vector SVGs (Iconify Brand Library)
     and high-density 128px fallback favicons.

C. Persistent Client & Server Databases:
   - Primary Storage: Server-side persistent JSON datastore (data/companies.json,
     data/companies_catalog.json, data/products_catalog.json, data/services.json).
   - Browser Storage: High-performance IndexedDB engines (VantagePulseDB and
     VantageCompaniesDB v3) enabling instant client-side offline querying.

Phase 3: Custom Domain & Free SSL Certificate
   - DNS CNAME Record: www -> <app-name>.azurewebsites.net
